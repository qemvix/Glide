# Changelog

## 1.0.0 — 2026-10-23

First public release of Glide.

- Native two-finger touchpad scrolling from a regular mouse wheel.
- Adjustable glide duration and movement speed.
- Vertical and horizontal scrolling.
- Per-app exclusions and full-screen app/game pausing.
- Discord and File Explorer exemptions from full-screen pausing.
- Windows wheel-routing awareness.
- Tray controls, optional startup, and Ctrl + Alt + S pause/resume.
- Local input diagnostics and settings persistence.
- Core regression tests and native touchpad receiver tests.

The release executable is the preserved build visually confirmed working in Discord and File Explorer.
